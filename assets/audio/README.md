# Game sound effects

The WAV effects in this folder are from **The Essential Retro Video Game Sound Effects Collection [512 sounds]** by Juhani Junkala.

- Collection page: https://opengameart.org/content/512-sound-effects-8-bit-style
- Source archive: https://opengameart.org/sites/default/files/The%20Essential%20Retro%20Video%20Game%20Sound%20Effects%20Collection%20%5B512%20sounds%5D.zip
- License: CC0 1.0 (public domain dedication), as stated in the collection's `INFO.txt`.

Included source files:

- `correct.wav` — `sfx_sounds_powerup5.wav`
- `level-up.wav` — `sfx_sounds_powerup1.wav`
- `incorrect.wav` — `sfx_sounds_error1.wav`
- `countdown.wav` — `sfx_menu_select1.wav`
- `finish.wav` — `sfx_sounds_fanfare1.wav`
